<h2>📘 Sobre</h2>

<p>
  Desenvolvedor desde 2020, com experiência em desenvolvimento backend e
  foco atual voltado à ciência de dados e engenharia de dados.

  Durante a graduação, atuei em uma equipe no desenvolvimento backend de
  um Gerenciador de Horários, sistema voltado à alocação de professores
  respeitando normas de atribuição. Nesse projeto, também exerci
  o papel de Product Owner (PO).

  Mais adiante, atuei como desenvolvedor backend e
  Scrum Master em um projeto para cliente real:   um serviço de
  interpretação automatizada de documentos financeiros, que reduziu o tempo de
  lançamento manual e os erros operacionais no fluxo de contas a pagar,
  combinando OCR, Processamento de Linguagem Natural (PLN) e IA/LLM
  para extração de dados.

  Atualmente, estou aprofundando meus estudos em análise de dados
  como base para atuar como cientista ou engenheiro de dados,
  com interesse particular em LLMs e no funcionamento interno da inteligência artificial.
  Aberto a oportunidades nas áreas de ciência/engenharia de dados e
  desenvolvimento backend.
</p>
